# Certifications & Training | Сертификаты и обучение

Репозиторий содержит подтверждения пройденного обучения и полученных квалификаций в области информационной безопасности, системного и сетевого администрирования.

Основные направления развития:

- Penetration Testing и анализ защищённости
- Network Security и анализ сетевого трафика
- SIEM и базовые процессы SOC
- Linux и Windows Administration
- Web Security
- Digital Forensics и OSINT
- Information Security Management
- Python для задач информационной безопасности

## Подтверждённые направления подготовки

На основании представленных документов обучение охватывает следующие области:

- основы информационной безопасности и управления рисками;
- ISO/IEC 27001 и системы менеджмента информационной безопасности;
- эксплуатация и конфигурирование R-Vision SIEM;
- основы мониторинга событий безопасности;
- тестирование на проникновение и анализ защищённости;
- безопасность веб-приложений;
- анализ сетей и сетевого трафика;
- Linux, Windows и PowerShell;
- безопасность баз данных;
- цифровая криминалистика;
- OSINT и исследование открытых источников;
- основы Python;
- практическая работа в учебных лабораториях TryHackMe.
